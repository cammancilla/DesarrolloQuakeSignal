Stack Tecnológico Integral

Mapa Tecnológico de QuakeSignal

Arquitectura tecnológica de extremo a extremo: desde el clic en la pantalla hasta la sirena en la calle

Versión: 2.0 Híbrida IoT + Cloud + Web
1

🖥️ Capa de Presentación y Centro de Control (Frontend)

Panel táctil del operador para monitorear sismos y activar el botón de pánico

Cliente Web 24/7
⚛️
React 19
Librería de UI reactiva con renderizado ultra rápido y componentes modulares.
🔷
TypeScript 5
Tipado estático riguroso para evitar errores de ejecución en emergencias críticas.
⚡
Vite 8
Empaquetador de última generación con inicio en milisegundos y hot-reload optimizado.
🎨
Tailwind CSS v4
Diseño responsive con soporte nativo de Modo Nocturno para centros de mando.
🗺️
Leaflet + CARTO
Mapas interactivos vectoriales con zoom automático al epicentro y cálculo de distancias.
2

⚙️ Capa de Negocio, Automatización y APIs (Backend Core)

Procesa eventos, audita accesos y planifica despachos sin bloquear el sistema

Node.js Engine
🟢
Node.js v24
Entorno de ejecución asíncrono no bloqueante con soporte de fetch nativo de alto rendimiento.
🚀
Express REST API
Rutas semánticas para botón de pánico, pings de nodos IoT y ajustes de configuración.
⏱️
Node-Cron
Reloj en segundo plano que vigila desconexiones de nodos cada 60s y despacha alertas cada 10s.
💾
Base Documental JSON
Almacenamiento liviano desacoplado en db.json para alertas, nodos y logs de auditoría sin latencia.
3

📜 Protocolos de Emergencia y Mensajería Estandarizada

Formatos que garantizan que el mensaje sea compatible mundialmente

Estándares Abiertos
🛡️
Estándar CAP v1.2 (ITU-T X.1303)
Estructura internacional de alerta de emergencias con campos de severidad, urgencia, área y polígono.
📡
Protocolo MQTT (TCP 1883)
Mensajería ultraligera Publish/Subscribe diseñada para enviar datos a microcontroladores con mínimo ancho de banda.
🔒
HTTP REST + JSON Payload
Canal de comunicación web seguro con serialización liviana y encabezados estandarizados.
4

☁️ Infraestructura Cloud y Difusión Push (Vía Internet)

Canal masivo para teléfonos móviles y coordinación de dispositivos en la nube

Nube & Telco
💬
Telegram Bot API
Bot oficial (@queakesignal_bot) que despacha alertas con formato Markdown directamente a los canales de la comunidad.
☁️
Broker MQTT (GCP / EMQX)
Servidor en la nube de alta disponibilidad que recibe el evento y lo retransmite al instante a todos los nodos suscritos.
🦊
GitLab Issue Boards
Plataforma de gestión ágil Kanban, control de versiones Git y trazabilidad completa de Historias de Usuario.
5

🚨 Resiliencia en Terreno y Hardware IoT (Modo Contingencia)

Equipamiento físico en plazas, colegios y postes para salvar vidas cuando se cae la red

Hardware Físico
📟
Microcontrolador ESP32
Procesador dual-core con Wi-Fi, Bluetooth y bajo consumo eléctrico que orquesta la estación comunitaria.
📢
Sirenas y Luces LED
Actuadores conectados a pines GPIO que emiten sonido penetrante y balizas estroboscópicas de advertencia.
📶
Portal Cautivo Wi-Fi (AP)
Red local autónoma que abre el plano de evacuación en celulares vecinos sin gastar saldo ni plan de datos.
📻
Canal RF 915 MHz (LoRa)
Banda libre de largo alcance que conecta los nodos entre sí cuando las antenas de telefonía se queman o caen.
